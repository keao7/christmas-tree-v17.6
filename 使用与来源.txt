Christmas Tree v17.6 / Grand Luxury Tree v17.6.5

网页入口：index.html。页面源代码为单文件，不需要编译。
联网加载 Three.js、MediaPipe 和相关模型；不是完全离线网页。
GitHub Pages 部署后使用 HTTPS，适合手机分享与摄像头手势。

使用方法
1. 空格键：聚合；Z：散开；X：抓取照片；方向键：旋转。
2. 手机端可使用底部按钮，单指拖动旋转，双指缩放。
3. 左侧可修改祝福语、字体、粒子，选择照片及 MP3 音乐。
4. 照片、音乐和设置保存在当前浏览器中，不会自动同步到其他人的设备。
5. 手势控制需用户允许摄像头；不用摄像头也能用按钮和键盘。

GitHub Pages 部署
将 index.html 和 .nojekyll 放在仓库 main 分支根目录。
进入 Settings → Pages → Deploy from a branch → main → /(root) → Save。
最终地址由 GitHub Pages 设置页给出。
官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
